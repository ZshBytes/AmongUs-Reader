# AmongUs-Reader

A Rust-based tool for **Among Us**.

##  Installation

### From Source

To build AmongUs-Reader from source, you'll need to install **Rust** first.

#### 1. Install Rust

Download and install Rust from the official website:

https://rust-lang.org/

#### 2. Clone the repository

```bash
git clone https://github.com/ZshBytes/AmongUs-Reader.git
cd AmongUs-Reader
```

#### 3. Build the project

```bash
cargo build
```

#### 4. Run the project

```bash
cargo run
```

For a release build:

```bash
cargo build --release
```

The compiled executable will be located in:

```text
target/release/
```

---

##  Installation for Normal People

Don't want to install Rust or mess around with source code?

Go to the **[Releases](https://github.com/ZshBytes/AmongUs-Reader/releases)** page and download the latest `.exe` release.

Run the executable and you're good to go.
